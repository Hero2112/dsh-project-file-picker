# v1.4.0 — 从「能看」变成「好用」：选中/双击、右键菜单、搜索、最近、内嵌预览

| 项 | 内容 |
|---|---|

| 版本类型 | 新功能（次版本） |
| 是否兼容旧数据 | 是（收藏表仍读 `pins.v3`，旧的 `pins.v1` 继续自动迁移） |
| 是否需要重启 DSH | 是（安装路径换成 `releases/v1.4.0`） |

这一版按「方便查看、快速操作」把面板整体重做了一遍：13 项改动。

## 交互：少点几下

- **单击选中、双击插入**：单击文件只选中（不再误插），双击文件插入 `@路径`；双击文件夹插入 `@路径/`。文件夹单击仍然是展开/收起。
- **多选批量插入**：Ctrl / Cmd 加选，底部出现「已选 N 项 → 插入引用」，一次插入多条引用；点空白处或「取消选择」清空。
- **右键菜单**：插入引用、用预览页签打开、在面板里预览、收藏/取消收藏、复制相对路径、复制绝对路径、复制 Markdown 链接、在文件管理器中显示、标记颜色和表情。
- **最近使用**：插入、预览、跳转都自动记一笔，最多 12 条，默认收起。

## 查看：看得更快更清楚

- **全项目搜索**：输入框右边加了放大镜。开启后输入关键字会**递归搜索整个工作目录**（自动跳过 node_modules、dist、.git 等），实时显示「已扫 N 个目录」，命中结果直接列出，双击插入。产品没有提供搜索 API，所以是插件自己按层并发扫的，带目录数/深度/结果数上限。
- **面板内预览**：右键 →「在面板里预览」，直接读文件前 400 行显示在右栏底部（带总行数、可再用预览页签打开）。图片 / 压缩包自动交给产品预览页签。
- **文件类型上色**：图标按扩展名分成代码 / 文档 / 图片 / PDF / 压缩包 / 表格 / 办公文档几组上色，行尾带扩展名徽标和文件大小。
- **行高两档**：紧凑 / 舒适，一键切换并记住。
- **层级引导线 + 隔行底纹**：深目录不容易看错层。
- **骨架屏**：目录读取时显示灰条占位，不再一行「正在读取…」。
- **错误提示条**：出错时在顶部出一条可关闭的红色提示，不再挤在底部。
- **排序**：名称 / 类型 / 大小三档循环，文件夹恒在前。
- **只看标记**：工具栏开关，只显示打过颜色或 emoji 的文件夹。

## 快速访问（收藏）增强

- 收藏区**可折叠**（状态记住），标题右侧显示「本对话 / 共用」。
- **收藏可以在对话之间共享**：点一下「本对话」切成「共用」，收藏存到共享格，所有对话都能看到；再点回来就又只属于当前对话。
- **拖拽排序**：收藏项左侧有手柄，直接拖到想要的位置。
- **导出 / 导入收藏**：导出成一个 JSON 文件，换机器或换浏览器时导回去（按路径去重合并）。

## 顺带做的

- **记住浏览位置**：每个对话记住展开到哪、滚到哪，切回来原地恢复。
- **大目录渲染优化**：行使用 `content-visibility`，几千条目的目录滚动更稳。

## 已知限制

- 递归搜索是客户端逐层扫目录，有上限（400 个目录 / 8 层 / 300 条结果）；超大仓库只扫一部分
- 面板内预览只读 UTF-8 文本前 400 行；Word / PDF / Excel 仍走产品预览页签
- 目录条目只带 `name / type / size`，没有修改时间，所以排不了「按时间」
- 「只看标记」按字面过滤：没打标记的中间层目录会被隐藏，浅层用的项目要留意
- 收藏、标记、最近、设置都存在浏览器 `localStorage`，不随会话同步
- 在文件管理器中显示需要这个 profile 支持 `remote.session.openWorkspacePath`，不支持的 profile 不会显示这一项
