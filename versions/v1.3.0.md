## 这一版做了什么

把「固定」这名字换成了更好懂的说法——**收藏**，区块标题叫「快速访问」。功能上也做实在了：

- **点收藏的文件夹 = 立刻展开 + 立刻跳过去**
  - 点下的瞬间就并行把**沿途每一层**目录读取都发出去，不再一层一层等
  - 祖先链一次展开到位，收藏的那个目录本身也是展开状态（直接看到里面的文件）
  - 目录行的数据一到位就自动滚到可见位置，并**闪一下高亮**，一眼看到跳到了哪
- 目录还在读的时候，底部提示「正在跳转到 xxx…」，读到后变成「已跳转到 xxx」
- 定位会重试：目录层没读完就每 80ms 再找一次，最多约 2.4 秒，不会只试一次就放弃
- 点收藏的**文件**还是直接插入 `@路径` 引用
- 收藏项鼠标悬停提示变成「点一下：展开并跳到这个目录」
- 刷新页面、切回这个对话，收藏项和已经展开的位置都还在；换个对话是另一套（v1.2.0 的行为不变）

## 使用方式

| 想做的事 | 怎么做 |
|---|---|
| 收藏一个常用文件夹 | 展开到能看到它 → 文件夹行悬停 → 点图钉 |
| 跳到收藏的文件夹 | 点「快速访问」里那一行，树会立刻展开并滚到那个目录（闪一下） |
| 从收藏的文件插引用 | 点「快速访问」里那个文件，直接插进输入框 |
| 取消收藏 | 点收藏项右侧的 `×`，或再点一次行上的图钉 |

数据没变，还是按键 `dsh.project-file-picker.pins.v3` 存，每个对话一格：

```json
{ "<会话 id>": [ { "path": "src/components", "kind": "directory" }, { "path": "src/main.js", "kind": "file" } ] }
```

## 已知限制

- 收藏的深目录层数越多，点一下要读的层就越多，第一屏还是会有点等待（读取期间有「正在跳转」提示）
- 高亮只闪约 1 秒，闪完就恢复普通样式；不会一直标着
- 收藏存在浏览器 `localStorage`，只在这台机器这个浏览器配置里有效，不随会话同步
- 收藏**按对话存**：换对话看到的是另一套，不会跨对话带过去
- 文件夹的颜色 / emoji 标记仍按工作目录共享，同一个项目下的几个对话都能看到
