## 这一版做了什么

v1.4.0 把「单击选中、双击插入」改上去之后，有两个手感问题：

- **双击文件夹会把它折叠**：双击其实是两次单击，每次单击都会翻转一次展开状态，两次正好抵掉，
  结果插入目录之后那一层被收起来了。现在双击会**只展开不折叠**，插入完照样停在那一层。
- **Ctrl / Cmd 加选时会连带展开/收起**：多选文件时顺手点几个文件夹会把树翻得乱七八糟。
  现在带修饰键的点击**只加选**，不改变展开状态。

## 使用方式

| 想做的事 | 怎么做 |
|---|---|
| 插入文件 | 双击文件行（单击只是选中） |
| 插入文件夹 | 双击文件夹行，插完这一层保持展开 |
| 多选 | Ctrl / Cmd 点行加选，底部「插入引用」一次插多条 |
| 展开 / 收起 | 不带修饰键单击文件夹行 |
