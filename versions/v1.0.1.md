# v1.0.1 — 改右侧页签的图标和名字

| 项 | 内容 |
|---|---|
| 发布日期 | 2026-11-03 |
| 版本类型 | 体验改进（改名 + 换图标） |
| 是否兼容旧数据 | 是（存储结构没动，标记不受影响） |
| 是否需要重启 DSH | 是（安装路径换成 `releases/v1.0.1`） |

## 这一版做了什么

- 改进：右侧边栏页签和「开始」页引导卡上的名字，从「项目文件」改成「项目文件坞」
- 改进：页签图标换成"文件夹落进对话框"——上面一个文件夹轮廓，中间一个向下箭头，下面是输入框轮廓，
  一眼能看出"把文件弄进对话框"
- 改进：引导卡描述补上后半句「可预览内容、给文件夹上色」
- 改进：英文文案同步改成 `Project file dock`
- 不变：功能、交互、快捷键、存储键都没动

## 使用方式

位置没变，右栏页签栏里那个页签，只是名字和图标换了。操作方式跟 v1.0.0 完全一样。

| 操作 | 怎么做 |
|---|---|
| 打开 | 右栏页签「项目文件坞」，或「开始」页的引导卡 |
| 插入文件 / 文件夹、预览、给文件夹上色 | 同 v1.0.0，见 [v1.0.0.md](v1.0.0.md) |

## 数据结构变化

无。`dsh.project-file-picker.tags.v1` 与 `dsh.project-file-picker.seeded` 都没动，标记照旧。

## 已知限制

- 图标是手写 SVG 线条图标，靠主题的 `currentColor` 上色，深浅色主题都跟随
- 页签名 5 个字，侧栏拖得很窄时会按页签自带规则省略
