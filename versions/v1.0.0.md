## 这一版做了什么

- 新增：右侧边栏的「项目文件」页签，按会话工作目录逐层浏览项目文件（顶部显示工作目录）
- 新增：点文件行或把文件行拖进输入框，插入 `@相对路径`（带空格的路径用 `@"..."`）
- 新增：**把文件夹插进对话框** —— 文件夹行悬停「插入此文件夹」按钮，或直接拖拽文件夹行，
  插入 `@相对路径/`（尾斜杠 = 目录，是产品自带的引用语法）
- 新增：文件行悬停「眼睛」按钮，用产品自带的预览页签打开文件内容；列表页签不被替换，
  可以边看边继续浏览、连续开多个预览
- 新增：文件夹标记 —— 悬停调色板按钮在行内展开面板，8 种颜色 + 16 个 emoji，
  可分别设置/取消/一键清除；文件夹图标染色、名字后跟表情
- 新增：筛选框（只在已加载的层里过滤）、刷新按钮、条目截断提示、失败原因提示、拖拽中提示
- 新增：中英文文案；首次安装后右栏自动展开一次并打开该页签（只做一次）
- 修复（开发中）：沿用了产品右栏页签体系，不再用底部小图标或浮层

## 使用方式

| 操作 | 怎么做 |
|---|---|
| 打开面板 | 右侧边栏页签「项目文件」（首次安装会自动展开一次；之后从右栏「开始」页的引导卡进入） |
| 展开目录 | 点文件夹行（再点一次收起） |
| 插入文件 | 点文件行，或把文件行拖进输入框 |
| 插入文件夹 | 悬停文件夹行 → 点「插入此文件夹」，或直接把文件夹行拖进输入框 |
| 查看文件内容 | 悬停文件行 → 点眼睛按钮（打开产品自带的预览页签） |
| 给文件夹上色 / 加表情 | 悬停文件夹行 → 点调色板按钮 → 选颜色 / 选 emoji；同项再点一次取消 |
| 重新读取 | 页签右上角刷新按钮（或右栏自带的刷新命令） |
| 筛选 | 顶部筛选框输入片段（只匹配已展开过的层） |

插入到输入框的文本：

| 内容 | 文本 |
|---|---|
| 文件 | `@src/main.js` |
| 含空格的文件 | `@"my file.txt"` |
| 文件夹 | `@src/components/` |
| 含空格的文件夹 | `@"my dir/"` |

## 数据结构变化

无旧数据。新增两个浏览器 `localStorage` 键：

```js
// dsh.project-file-picker.tags.v1 —— 文件夹标记，按「工作目录 + 相对路径」记录
{
  "F:/proj/demo": {
    "src/components": { "color": "#e5484d", "emoji": "🔥" }
  }
}

// dsh.project-file-picker.seeded —— 首次自动展开右栏只做一次
"1"
```

文件内容不缓存、不复制；目录按需读取；预览交给产品自带的预览页签。

## 已知限制

- 文件夹标记存在浏览器 `localStorage`：不随会话同步、换设备看不到、不同浏览器官网配置各一套
- 标记按「工作目录」分区，换项目看到的是另一套
- 目录按需加载：未展开过的层不参与筛选；单层条目过多会截断
- 只能浏览会话工作目录内部，不能越界到其它路径
- 点击文件行是「插入引用」，不是「打开文件」；打开内容要点眼睛按钮
- 预览依赖产品自带的预览页签，无法渲染的类型会显示原生「不可预览」提示
- 插件目录若在同步盘里，同步客户端生成的 `locale/*.sync-conflict-*.json` 会让插件列表的
  显示名报「包元信息错误」（功能不受影响，删掉该副本即可）
