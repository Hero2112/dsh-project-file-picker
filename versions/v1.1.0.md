## 这一版做了什么

目录很深、又经常要用同一个文件夹时，每次都得一层层点进去很烦。这一版加了**固定**：

- 文件行、文件夹行悬停时多了一个**图钉按钮**，点一下就把这个位置固定住
- 固定的位置出现在列表上方的「固定」区，显示「名字 + 相对路径 + ×（取消固定）」
- 固定的**目录**：打开面板（刷新页面、切换会话、重新进这个项目）时会**自动展开到那一层**，
  点固定项直接跳过去并把那一行滚到可见位置，不用再手动一层层点
- 固定的**文件**：点固定项直接把 `@路径` 插进输入框，跟点文件行一样
- 固定一直在，直到你点 `×` 或再点一次图钉取消；按工作目录各存一套

顺手修：把网盘同步产生的 `*.sync-conflict-*` 副本挡在仓库外（`.gitignore` 补了规则），
`INSTALL.md` 里的示例安装路径更新到当前版本。

## 使用方式

| 想做的事 | 怎么做 |
|---|---|
| 固定一个深目录 | 展开到那一层 → 把鼠标放到文件夹行上 → 点图钉（固定后图钉变亮） |
| 固定一个常用文件 | 把鼠标放到文件行上 → 点图钉 |
| 回到固定的目录 | 点「固定」区里那一行，目录自动展开并跳过去 |
| 从固定的文件插引用 | 点「固定」区里那个文件，直接插进输入框 |
| 取消固定 | 点固定项右侧的 `×`，或再点一次行上的图钉 |

固定的数据按键（`dsh.project-file-picker.pins.v1`）：

```json
{ "<工作目录>": [ { "path": "src/components", "kind": "directory" }, { "path": "src/main.js", "kind": "file" } ] }
```

数组顺序就是显示顺序，最新固定的排在最前面；`path` 是相对工作目录的路径，换机器只要路径结构一样就能继续用。

## 已知限制

- 固定的深目录打开时要逐层读取沿途目录，层数多时第一屏会稍慢；读取失败的那一层会显示错误提示，不影响其他层
- 固定项存在浏览器 `localStorage`，只在这台机器这个浏览器配置里有效，不随会话同步
- 固定只记「路径 + 类型」，不记展开后的滚动位置；点击固定项会滚到那一行，但不会恢复到上次的滚动偏移
- 固定的文件不会自动出现在「筛选」结果里（筛选只看已展开层的文件），但固定区始终可见
