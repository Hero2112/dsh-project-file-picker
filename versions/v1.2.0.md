| 项 | 内容 |
|---|---|
| 发布日期 | 2026-11-04 |
| 版本类型 | 行为调整（次版本） |
| 是否兼容旧数据 | 是（旧的固定项自动迁到当前对话） |

## 这一版做了什么

上一版的固定项是「按工作目录存一套」，同一个项目下的几个对话会共用同一份，
在 A 对话里固定了，B 对话里也冒出来。这一版改成**按对话各存一套**：

- 在哪个对话里固定的文件夹 / 文件，就只出现在那个对话的「固定」区
- 换个对话是另一套，互不相关；在那个对话里固定也不会影响别的对话
- 同一个对话刷新页面、切走再切回来，固定项和原来一样还在，深目录照样自动展开
- 固定区的标题上有提示：「固定项只属于当前这个对话，换个对话是另一套」

顺带处理：旧版（1.1.0）的固定项存在 `dsh.project-file-picker.pins.v1`（按工作目录分组）。
升级后第一次打开某个对话时，属于这个工作目录的旧固定项会**归到当前对话**，
然后从旧键里删掉（同一个项目下另一个对话不会再拿到同一批），所以旧数据不会丢也不会重复。

## 使用方式

跟上一版一样，只是作用范围变了：

| 想做的事 | 怎么做 |
|---|---|
| 固定一个深目录 | 在当前对话里展开到那一层 → 文件夹行悬停 → 点图钉 |
| 回到固定的目录 | 点「固定」区里那一行，目录自动展开并跳过去 |
| 从固定的文件插引用 | 点「固定」区里那个文件，直接插进输入框 |
| 取消固定 | 点固定项右侧的 `×`，或再点一次行上的图钉 |
| 换一个对话用另一套固定 | 直接换对话就行，不需要设置 |

数据按键（`dsh.project-file-picker.pins.v3`）：

```json
{ "<会话 id>": [ { "path": "src/components", "kind": "directory" }, { "path": "src/main.js", "kind": "file" } ] }
```

每个对话一格；数组顺序就是显示顺序，最新固定的排在最前面。

## 数据结构变化

| 存储键 | 变化 |
|---|---|
| `dsh.project-file-picker.pins.v3` | 新增。按对话（会话 id）存固定项 |
| `dsh.project-file-picker.pins.v1` | 旧键。首次读取时把属于当前工作目录的那一组归到当前对话，并从这里删掉 |
| `dsh.project-file-picker.tags.v1` | 不变（文件夹标记仍按工作目录共享） |
| `dsh.project-file-picker.seeded` | 不变 |

## 已知限制

- 固定项存在浏览器 `localStorage`，只在这台机器这个浏览器配置里有效，不随会话同步
- 固定项按对话存，所以**不会跨对话共享**；想在多个对话里都有同一个目录，需要在每个对话里各固定一次
- 会话 id 变了（比如删了对话重建）就看不到原来那份固定项
- 文件夹的颜色 / emoji 标记仍然按工作目录共享，同一个项目下的几个对话都能看到
- 固定的深目录打开时要逐层读取沿途目录，层数多时第一屏会稍慢
