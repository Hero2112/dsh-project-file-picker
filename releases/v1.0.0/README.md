# 项目文件坞（Project File Dock）v1.0.0

DeepSeek Harness Web UI 插件：在**右侧边栏**里浏览当前项目（会话工作目录）的文件，
把文件或文件夹拖进对话框，顺手预览文件内容，给文件夹打颜色和表情标记。

## 打开方式

右侧边栏（右栏）的页签栏里有一个「项目文件」页签。首次安装后侧栏会自动展开一次并打开它；
之后从右栏「开始」页的引导卡（`项目文件`）进入。

## 功能

| # | 能力 | 用法 |
|---|---|---|
| 1 | 浏览项目文件 | 右栏页签内按会话工作目录逐层展开；顶部显示工作目录，右上角刷新按钮重新读取 |
| 2 | 筛选已加载文件 | 顶部筛选框只在「已经展开过的层」里过滤，不触发新的目录读取 |
| 3 | 插入文件 | 点击文件行 = 在当前光标处插入 `@相对路径`；拖拽文件行到输入框 = 在落点处插入 |
| 4 | 插入文件夹（选目标目录） | 文件夹行悬停出现「插入此文件夹」按钮，或直接拖拽文件夹行到输入框 → 插入 `@相对路径/` |
| 5 | 查看文件内容 | 文件行悬停出现眼睛按钮，点击用产品自带的预览页签打开该文件（markdown / 图片 / 文本行号等）；列表页签不被替换，可继续浏览、连续开多个预览 |
| 6 | 文件夹标记 | 文件夹行悬停出现调色板按钮，行内展开标记面板：8 种颜色 + 16 个 emoji，可分别设置、可取消、可一键清除；文件夹图标染色、名字后跟表情 |
| 7 | 中英文文案 | 跟随 DSH 语言设置 |

## 插入语法（用产品自带的引用语法，不自造标记）

| 内容 | 写进输入框的文本 | 说明 |
|---|---|---|
| 文件 | `@src/main.js` | 尾字符不是斜杠 = 文件引用 |
| 含空格的文件 | `@"my file.txt"` | 引号包裹 |
| 文件夹 | `@src/components/` | **尾斜杠 = 目录**，引用会渲染成文件夹样式的标签 |
| 含空格的文件夹 | `@"my dir/"` | 闭合引号，斜杠在引号内 |

模型侧收到的固定说明是「尾斜杠代表目录，需要时列出其内容」，所以插入文件夹等于告诉模型
「对这个目录操作」，不会被当成文件去 read。

## 数据结构

| 存储 | 键 | 内容 |
|---|---|---|
| 浏览器 `localStorage` | `dsh.project-file-picker.tags.v1` | 按「工作目录 + 相对路径」记录文件夹标记：`{ "<root>": { "<relPath>": { "color": "#hex", "emoji": "🔥" } } }` |
| 浏览器 `localStorage` | `dsh.project-file-picker.seeded` | 首次自动展开右栏只做一次 |

文件内容本身不缓存、不复制：目录按需读取，预览交给产品自带的预览页签。

## 已知限制

- 文件夹标记存在浏览器 `localStorage`，只在这台机器这个浏览器配置里有效，不随会话同步（Harness 目前没有给客户端插件提供 KV 服务）。
- 标记是**每个工作目录**一套；换项目（工作目录）看到的是另一套标记。
- 目录按需加载，未展开的层不参与筛选；条目过多时该层会显示「只显示了一部分」。
- 只作用于会话工作目录内部，不能浏览工作目录之外的路径。
- 插件目录若放在同步盘里，同步客户端可能生成 `locale/zh.sync-conflict-*.json`，导致插件列表的显示名报「包元信息错误」（功能不受影响）。处理办法见排错一节。

## 排错

**「包元信息错误：… must use a language id as its filename」**

Harness 读取插件显示名时，会把 `locale/` 下**每个** `*.json` 的文件名当作语言 id 校验
（`^[A-Za-z]{2,8}(-[A-Za-z0-9]{1,8})*$`）。同步盘生成的冲突副本文件名不符合规则，整条元信息就报错
（插件功能不受影响，只是插件列表里的名称/描述显示不出来）。

处理：删掉 `locale/` 下所有 `*.sync-conflict-*.json`，只保留 `zh.json`、`en.json`，
重新加载插件列表即可。想彻底避免，把插件目录移出同步盘后再安装。
